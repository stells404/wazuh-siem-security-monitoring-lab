# Wazuh Agent Deployment Evidence

This directory documents endpoint agent deployment and agent status verification in the Wazuh SIEM laboratory.

## Evidence

- **Wazuh agent overview:** Documents the agent status displayed in the Wazuh dashboard.
- **Endpoint agent details:** Provides supporting evidence of an enrolled endpoint agent.

## Security and Evidence Notes

- Public screenshots must be reviewed and sanitized to remove original lab IP addresses, unnecessary host identifiers, and other environment-specific information.
- Screenshots must preserve the original observed results.
- Agent status reflects the state shown at the time of capture.

## Scope

This evidence supports the endpoint monitoring and telemetry collection stages of the laboratory.
